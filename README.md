This is a web-based Employee Task Management System that allows assigning, tracking, and managing tasks efficiently.

📌 Project Overview

The purpose of this project is to simplify task management between employees and improve workflow organization.

🛠️ Tech Stack
HTML
CSS
JavaScript
Local Storage

⚙️ Features
Assign tasks to employees
View all tasks in a structured format
Track task status (pending/completed)
Simple and user-friendly interface

👨‍💻 My Contribution
I developed this project to understand how real-world task management systems work and how tasks are handled in a team environment.

🔄 How It Works
Tasks are created and assigned
Data is stored (local storage / backend)
Tasks are displayed dynamically
Users can update task status

🚀 Learning Outcomes
DOM manipulation
Event handling
Data management
Building real-world logic-based applications
